# Тамагочи за Мак 🐣

Малко пикселно животинче, което стои най-отгоре на екрана, разхожда се по дъното
му и иска храна, игра и сън. Няма икона в Dock: управлява се от иконката в горната
лента (🐣 / 🥺 / 💤 / 👻) или с десен бутон върху самото животинче.

## Инсталиране

### Вариант А: готово приложение от GitHub
1. В GitHub → **Actions** → „Tamagotchi (macOS)“ → последното изпълнение →
   свали **Tamagotchi-mac** (zip).
2. Разархивирай и сложи `Tamagotchi.app` в папка **Applications**.
3. Първия път: **десен бутон → Open → Open** (приложението не е подписано от Apple).
   Ако macOS пак откаже: в Терминал
   `xattr -dr com.apple.quarantine /Applications/Tamagotchi.app`

### Вариант Б: сглобяване на самия Мак
Трябват само Command Line Tools (`xcode-select --install`, ако ги няма).

```
cd tamagotchi
./build.sh install
```

## Как се гледа

| действие | какво прави |
| --- | --- |
| клик върху него | гали го (сърчица, малко радост) |
| влачене | местиш го където искаш |
| посочиш го с мишката | показват се 4 черти: ситост, радост, енергия, здраве |
| десен бутон / иконката горе | менюто: нахрани, играй, лекарство, приспи/събуди… |

* Гладува, скучае и се уморява с времето; когато нещо му липсва, казва го в балонче.
* Когато енергията свърши, заспива само и се събужда наспано.
* Ако дълго е гладно или изтощено, губи здраве; при ниско здраве позеленява и
  трябва лекарство. При нула здраве си отива (👻) и може да се излюпи ново.
* Докато приложението е спряно или Мак-ът спи, времето тече 3 пъти по-бавно и
  животинчето не губи здраве, така че нощта не е опасна.
* В менюто: „Разхожда се“, „Смени името…“, „Пускай при включване“.

## Код

Всичко е в `Sources/main.swift` (AppKit, без външни библиотеки). Спрайтовете са
низове 16×16, по един символ на пиксел, така че лесно се рисуват нови.
